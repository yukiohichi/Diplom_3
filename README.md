# UI-тесты для веб-приложения бургера

Проект автоматизации UI-тестирования с использованием **Selenium**, **pytest** и **Allure**, покрывающий основные пользовательские сценарии сайта конструктора бургеров.

## Структура проекта

- `tests/` — тестовые сценарии, разделённые по функциональным зонам (аккаунт, навигация, лента заказов и т.д.)
- `pages/` — Page Object классы, инкапсулирующие взаимодействие с UI
- `locators/` — локаторы, сгруппированные по страницам
- `data/` — вспомогательные данные (генераторы, URL'ы, константы)
- `conftest.py` — фикстуры для запуска, авторизации и создания заказов

## Покрытие тестами

- Авторизация и выход
- Восстановление пароля
- Навигация по сайту
- Работа раздела "Конструктор"
- Создание и отображение заказов
- Работа раздела "Лента заказов"
